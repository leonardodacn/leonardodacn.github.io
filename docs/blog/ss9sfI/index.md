# git 查看远程地址


有时需要查看本地开发的git项目的远程仓库地址

`git remote -v` 可以方便的查看远程仓库的地址
```
git remote -v                                                                                        
origin  https://gitee.com/leonardodacn/pixiublog.git (fetch)
origin  https://gitee.com/leonardodacn/pixiublog.git (push)
```
-v : verbose，冗余的意思
